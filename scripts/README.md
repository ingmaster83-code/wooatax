# 우아세금 생성 스크립트

데이터 파일 없이 현행 세법 규칙으로 계산해 정적 페이지를 만든다.

- `tax.py` — 취득세·증여세·상속세·재산세 계산(모든 세율·공제 상수가 여기 한 곳). 세법 개정 시 이 파일만 수정.
- `build_site.py` — `_site/` 생성(약 1초, 572페이지). 배포는 GitHub Actions가 빌드.
- `assets/js/calc.js` — 브라우저 계산기(같은 식). `test_calc.js` + `test_calc.py` 로 파이썬과 대조(160케이스).
- 점검: `check_site.py`, `peek.py <경로>`.
- 매년 초: 세율·공제·특례 일몰(재산세 1세대1주택 특례 2026-12-31 한시, 상속세 개편 논의)을 확인하고 `tax.py`·about 페이지 문구 갱신.
